# CloudBox - Responsive Pricing Cards

CloudBox is a simple responsive pricing cards website created using HTML, CSS, and JavaScript.

This project shows different cloud storage plans for students, professionals, and businesses. Users can also switch between monthly and yearly pricing.

## Features

- Three pricing plans: Student, Pro, and Business
- Monthly and yearly price options
- Responsive design for mobile and desktop
- Most Popular plan highlighted
- Hover effects on cards and buttons
- Plan selection using JavaScript alert
- Simple navigation bar and footer

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Pricing Plans

### Student
- 20 GB Cloud Storage
- 1 User Account
- Mobile Access
- Email Support

### Pro
- 100 GB Cloud Storage
- 3 User Accounts
- File Sharing
- Priority Support

### Business
- 500 GB Cloud Storage
- 10 User Accounts
- Advanced File Sharing
- 24/7 Support
